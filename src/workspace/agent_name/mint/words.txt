# litany agent-name wordlist — 541 words. TWO are drawn and joined in
# PascalCase as an agent name (`PeachHollow`) when a creation path omits
# `name` (ARCH §2.3, bl-79a2). The mint's whole pool is the ordered pairs of
# distinct words — 541 × 540 = 292,140 names — and that pair space, not this
# list's length, is the bound on its collision-retry scan.
#
# Every word must therefore read well in BOTH positions of a pair, since the
# mint may put any word before or after any other.
#
# PROVENANCE: authored for this repository. No third-party corpus was
#   copied, filtered, sampled or diffed to produce it — the words were
#   written out by category (weather, landscape, plants, food, materials,
#   colours, tools, instruments, buildings, animals, textures, crafts) and
#   screened by hand. It carries no attribution obligation to anyone: it is
#   part of this crate and is covered by the crate's own licence (MIT, see
#   LICENSE), like every other file here. It replaces an EFF-derived,
#   CC BY 4.0 list (bl-b59c) — replaced rather than pruned, because a
#   filtered copy of that list would still be an adaptation of it and would
#   still owe the notice.
#
# WHY 541 AND NOT THOUSANDS. The pool sizes the *occupied-set* problem, and
#   the occupied set is one workspace's living agents (ARCH §2.3) — tens,
#   and recycled the moment retention (§9.2) deletes a ref. A collision is
#   not a failure, only a scan step; exhaustion needs every one of these 541
#   worn at once, and is loud rather than a loop. Against that, a small list
#   buys the two things a big one cannot: it can be *read* end to end by a
#   human, which is what makes the approval below meaningful, and every word
#   is one an operator can say aloud and remember.
#
# INVARIANTS a consumer may rely on, all pinned by
# `src/workspace/agent_name/mint/tests.rs`:
#   - every word matches ^[a-z]{3,9}$ — so a name is path-safe on every
#     supported filesystem, shell-safe unquoted, and case-unambiguous;
#   - the words are unique and sorted, so a diff of this file is reviewable;
#   - every word is a concrete, neutral, everyday English noun or adjective:
#     no proper noun, no brand, no personal name, and nothing violent,
#     sexual, medical, political or insulting. An agent wears its name in
#     front of an operator; the mint may not put a slur in their mouth;
#   - no word is a plausible human identity, so a minted name can never be
#     mistaken for a $USER-stamped or "unknown"-stamped claimant;
#   - lines beginning with '#' and empty lines are comments; skip them.
#
# ADDING A WORD IS A REVIEW EVENT. The test pins this set by digest and by
# count, so any edit fails the suite until both lines are updated by hand —
# that is the approval record, and it is the point, not a nuisance.
