Implements docs/DESIGN_CONTEXT_ECONOMY.md section 5.3 (C.iii, the extract).
- New src/prompt/compactor/extract.rs: a pure function from (the transcript entries present at the compaction point and absent from the base) to the extract text. Sections in fill order under one byte cap: verbatim user messages (messages/NNN-user.md bodies), error strings (last lines of is_error tool results and non-zero exit tails), pull-request numbers (#NNN, pull/NNN), commit shas (7-40 hex), paths (slash-separated tokens with an extension). Each section deduplicated, newest first; the cap cuts the first overflowing section with the ARCH 3.3 marker. No model, no tokenizer, no I/O beyond the tree reads.
- src/prompt/compactor/land/base.rs: the base commit gains summary/NNN.refs.md beside the compactor's summary/NNN.md when compaction.intermediate.extract_bytes is set; the compaction product definition (what the landing carries) widens to deletions + summary + extract and nothing else. The compactor's toolset is unchanged.
- src/config/workflow/compaction.rs: extract_bytes: Option<usize>; template/workflow.yaml ships 32768; omitted = no extract (severable).
- src/prompt/compactor/tools.rs: this pass's own extract joins the not-eligible class exactly as its summary does; an earlier pass's extract stays nominable.
