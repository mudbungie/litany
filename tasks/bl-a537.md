Implements docs/DESIGN_CONTEXT_ECONOMY.md section 5.1 (C.i, the window trigger).
- src/config/workflow/compaction.rs: CompactionTrigger gains WindowPercent; n is the percentage (1..=100 else declined at parse); keep_recent's must-stay-below-n rule applies only to every_n_commits, unchanged.
- src/prompt/compactor/checkpoint.rs state/due: the numerator is the last usage read from the newest messages/NNN-<model-id>.json in the read-state tree (src/prompt/dispatch/entry.rs UsageReport is the shape's one home): input_tokens + cache_read_tokens + cache_write_tokens, absent counters contributing nothing, never steps/. The denominator is the context_window the same usage report carries (brazen delivers it in-band on the Usage event; brazen ball referenced from the design doc section 5.1). A branch whose last usage carries no window while the workflow names window_percent is declined at the boundary naming the model and the trigger — never a trigger that silently never fires. No last usage yet (step 1) = not due.
- template/workflow.yaml: comment documents the variant; the shipped trigger stays every_n_commits until the brazen field ships, then a follow-up flips the default to window_percent n: 50.
