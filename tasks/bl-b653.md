bl-f838 holds every declared control equal by construction, but time is an undeclared one: variants execute sequentially within an invocation, so provider-side change mid-evaluation biases later arms. Interleave the execution order across variants (round-robin or a seeded shuffle at the (experiment, task, run) grain) so drift lands evenly. The record already carries per-run observations, so no schema change; run directories are already namespaced per variant, so ordering is free to move.
