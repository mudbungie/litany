Every brazen pin move so far was a hand-filed ball (bl-143e, bl-8daa, bl-cdcb, bl-5491). The publish side is automatic and so is every endpoint's install; the pin is the one link a person carries.

Shape: `make ingest` (a script under scripts/, self-tested under fake curl/cargo shims like the deploy self-test) reads the newest non-yanked brazen off the sparse index, rewrites the pin's one home in Cargo.toml, moves the lockfile with `cargo update --precise`, writes the changelog bullet and promotes the changelog so the release hold clears. No newer brazen is the same path with an empty diff, not a branch. `.github/workflows/ingest.yml` runs it hourly and on dispatch and lands a non-empty diff the way yog's advisories.yml lands a lockfile mend: branch, dispatch ci.yml, fast-forward main on green, delete the branch, dispatch release-plz.yml. A red gate is a hand's case and leaves main untouched.
