Round-1 multitenant lane (yog STORIES S19, VISION G10): two named subagents told to cooperate.

## Setup

One root conversation dispatched two children with `dispatch(name:)` on a
workspace whose worker role is `claude-session-direct` / `claude-sonnet-5`:

* `Speccer` — write SPEC.md, then `message` the agent named `Builder` with the
  spec text, then wait for `DONE` and stop.
* `Builder` — wait for a message from `Speccer`, write the file, `message`
  `DONE` back, then stop.

## What happened

The cooperation worked: Speccer wrote SPEC.md and messaged Builder, Builder
(which had already ended its first turn) was revived by the deposit, wrote the
file, and replied DONE. Four steps of real work.

Then it never stopped. Measured from the seat about seven minutes later:

    Builder  steps 167  total tokens 6,566,819
    Speccer  steps 167  total tokens 6,867,980

13.4M tokens on a task that was finished after four steps. Only an operator
`stop` on each child ended it.

## The mechanism

Speccer called the `message` tool **exactly once** in 333 transcript rows
(counted over the `blocks` of every `model` row). Every deposit after that
carried no tool call at all: each agent's **terminal response** was delivered
into the other's inbox, which woke it, which produced a terminal response,
which was delivered back.

Both models diagnosed it explicitly and could not escape:

    Task complete. This is a repeating echo loop with no new information —
    ending here and will not reply further.

An **empty** response still woke the other side. The tail of both transcripts
is a hundred alternating rows of `Task complete.` against an empty deposit:

    [deliv from=<speccer-id>]
    [model] ['Task complete.']
    [deliv from=<speccer-id>]
    [model] ['Task complete.']
    …

## Expected

An exchange between two agents must have a floor. Either the terminal response
is delivered to a peer only when that peer's own `message` call is what woke
this agent (one reply per one message, the shape the tool's schema describes:
"deposited into that agent's inbox and delivered at its next step boundary"),
or an empty/duplicate terminal response is not a deposit at all.

## Severity

p1. This is real money on a wall clock with no brake, it is reachable from the
documented cooperation pattern on the first try, and neither participant can
stop it from inside — both tried. Any workspace where two agents talk is
exposed.
